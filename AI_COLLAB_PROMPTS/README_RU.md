# Персональные промпты команды EVERREALM

Общий порядок старта и проверка доступа: [TEAM_START_PROMPT_RU.md](../TEAM_START_PROMPT_RU.md). Правила хранения и работы с файлами: [AI_STORAGE_POLICY_RU.md](../AI_STORAGE_POLICY_RU.md).

Передайте каждому участнику общий стартовый промпт, актуальный мастер V3.1 из проекта, ровно его ролевой файл ниже и конкретный TASK_BRIEF. Ролевой файл не является самостоятельным назначением production-задачи.

| Участник | Персональный промпт | Основная ответственность |
|---|---|---|
| Claude Opus 5.5 | [CLAUDE-OPUS-5.5_RU.md](roles/CLAUDE-OPUS-5.5_RU.md) | Художественное руководство анимацией, приёмка моделей, назначенная интеграция |
| Claude Fable 5.2 | [CLAUDE-FABLE-5.2_RU.md](roles/CLAUDE-FABLE-5.2_RU.md) | Оригинальные игровые модели и геометрия |
| Codex GPT-6.1 Sol Ultra | [CODEX-GPT-6.1-SOL-ULTRA_RU.md](roles/CODEX-GPT-6.1-SOL-ULTRA_RU.md) | Rig, bone blueprint, retarget и инженерия движения |
| Codex GPT-6 Luna Ultra | [CODEX-GPT-6-LUNA-ULTRA_RU.md](roles/CODEX-GPT-6-LUNA-ULTRA_RU.md) | Оригинальные художественные референсы и промпты |
| ChatGPT — координатор | [CHATGPT-COORDINATOR_RU.md](roles/CHATGPT-COORDINATOR_RU.md) | Назначение задач, границ, квоты и handoff |

**Квота Claude:** Fable и Opus используют общий Claude Pro ресурс. Не планировать их как независимые оплаченные аккаунты; координатор распределяет недельную квоту до назначения задач.

**Последовательность типовой модели:** Luna — художественный пакет → Sol — проверенная техническая спецификация → Fable — оригинальная модель → Opus — художественный review → назначенная интеграция → независимый QA → приёмка главным разработчиком.

Используйте отдельные TASK_ID и worktrees для параллельных изменений. Квоты, доступ к моделям, локальные файлы и репозиторий каждый участник обязан подтвердить в своей сессии. Роли не дают права на автоматическую отправку сообщений, публикацию, merge, удаление файлов или изменение main.
